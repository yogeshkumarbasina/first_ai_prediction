# AI Sentiment Analyzer 🤖

A modern AI-powered Sentiment Analyzer built using Flask, Machine Learning, and NLP.

This application predicts whether user input text is:

- 😊 Positive
- 😠 Negative
- 😐 Neutral

---

# 🚀 Features

- Real-time sentiment prediction
- Beautiful responsive UI
- Positive, Negative, Neutral detection
- Flask web application
- Machine Learning integration
- NLP text processing
- GitHub portfolio project

---

# 🛠️ Technologies Used

- Python
- Flask
- Scikit-learn
- Machine Learning
- NLP (Natural Language Processing)
- HTML
- CSS

---

# 📷 Project Preview

Users can enter text like:

```text
I really love this application
```

And the AI predicts:

```text
😊 Positive
```

# ▶️ How to Run

## 1 Clone Repository

```bash
git clone https://github.com/YOUR/yogeshkumarbasina/first-ai-prediction.git
```

---

## 2 Move Into Project Folder

```bash
cd first-ai-prediction
```

---

## 3 Install Requirements

```bash
pip install -r requirements.txt
```

---

## 4 Run Flask App

```bash
python app.py
```

---

## 5 Open Browser

```text
http://127.0.0.1:5000
```

---

# 🧠 Machine Learning Model

This project uses:

- CountVectorizer
- Multinomial Naive Bayes

for sentiment classification.
